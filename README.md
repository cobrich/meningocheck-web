# MeningoCheck/Ai web demo

Статический демонстрационный сайт для предварительной оценки риска менингита.

> Это не медицинское изделие и не средство диагностики. При опасных симптомах
> следует немедленно обратиться за экстренной медицинской помощью.

## Локальный запуск

Откройте `index.html` в браузере или запустите простой локальный сервер:

```bash
python3 -m http.server 8080
```

После этого сайт будет доступен по адресу <http://localhost:8080>.

## Деплой на Render

1. Создайте отдельный Git-репозиторий из содержимого этой папки и отправьте его
   в GitHub, GitLab или Bitbucket.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. Render прочитает `render.yaml` и создаст Static Site без этапа сборки.

Альтернатива без Blueprint: выберите **New → Static Site**, оставьте Build
Command пустым и укажите `.` в Publish Directory.

## Ограничения демо

- Регистрация и код подтверждения имитируются в браузере.
- Аккаунты и история проверок сбрасываются после перезагрузки страницы.
- Для настоящей авторизации, email и постоянного хранения нужен отдельный backend.
