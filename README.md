# MeningoCheck/Ai web demo

Веб-приложение для предварительной оценки риска менингита: аккаунты с
подтверждением email, сохранение результатов и личный кабинет.

> Это не медицинское изделие и не средство диагностики. При опасных симптомах
> следует немедленно обратиться за экстренной медицинской помощью.

## Локальный запуск

Нужен PostgreSQL. Скопируйте `.env.example` в `.env`, заполните подключение к
базе и SMTP, затем выполните:

```bash
npm install
set -a; source .env; set +a
npm start
```

После этого сайт будет доступен по адресу <http://localhost:3000>. Если SMTP не
настроен в development-режиме, код подтверждения появится в консоли сервера и в
интерфейсе. В production отправка почты обязательна.

## Деплой на Render

1. Отправьте изменения в GitHub, GitLab или Bitbucket.
2. В Render выберите **New → Blueprint** и подключите репозиторий.
3. Render создаст Node Web Service и PostgreSQL из `render.yaml`.
4. Заполните секретные переменные `SMTP_HOST`, `SMTP_USER`, `SMTP_PASS` и
   `SMTP_FROM` в Render Dashboard. Для порта 465 также задайте
   `SMTP_PORT=465` и `SMTP_SECURE=true`.

> Render блокирует исходящие SMTP-порты 25, 465 и 587 на бесплатных Web
> Services. Для SMTP требуется платный instance. На бесплатном instance вместо
> SMTP необходимо использовать почтовый сервис с HTTPS API.

## Ограничения демо

- Расчёт является эвристикой прототипа, а не клинически валидированной моделью.
- Сервис не ставит диагноз и не заменяет экстренную медицинскую помощь.
